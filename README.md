RupAI — Real & Fake Indian Currency Detection

RupAI is a simple AI tool to detect whether an Indian currency note is real or fake using a pre-trained model.

⸻

Features
	•	Load a pre-trained model.
	•	Upload an image of currency.
	•	Predict Real or Fake instantly.
	•	Streamlit interface for easy testing.

⸻

Tech Stack
	•	Python
	•	TensorFlow / Keras
	•	Streamlit
	•	OpenCV, NumPy
